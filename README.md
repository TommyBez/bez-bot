# Bez Bot

AI teammates that own a job end to end, built on [eve](https://eve.dev). A working clone of the x.ai/bot product (not affiliated with xAI).

The app lives in [`my-agent/`](my-agent). See [`my-agent/README.md`](my-agent/README.md) for features, architecture, the autonomous bot network, and how to run and deploy it.

```bash
cd my-agent
pnpm install
pnpm dev:eve   # once: /login to connect the model through the Vercel AI Gateway
pnpm dev
```
